## 🚀 Getting Started

### 1. Clone the repository



```bash
git clone https://github.com/yasser2006399/qrcodegenerator.git
cd qrcodegenerator
```

### 2. Create a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install the requirements

```bash
pip install -r requirements.txt
```

### 4. Run the program

```bash
python main.py
```
